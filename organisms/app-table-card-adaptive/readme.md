# table-card-adaptive — универсальная карточка таблицы (адаптив) — организм

Универсальная мобильная карточка: при адаптиве строка таблицы превращается в такую карточку.
Собрана как **агрегат всех четырёх примеров** — в одной карточке сведены решения каждого
источника (первый блок демо-стенда — она сама, с тумблерами частей). Возможно, карточек будет
несколько — это первая.

Источники (Figma):

- **6400:15954** «Table content mobile» (старая ДС) — товар: заголовок 16/24 + ⋮,
  серая подпись, иконочная строка (коробка 20 + текст 12), разделитель, 3 строки 14/20;
- **6354:14931** «Purchase invoice mobile» (старая ДС) — накладная: заголовок + ⋯, статус
  строкой под заголовком, подпись; мини-вариант — строки с иконками 18/24 (в паре гэп 4,
  между парами 16, иконка-действие в конце строки);
- **8188:18900** «Mobile card» (старая ДС) — инвентаризация: заголовок, подпись-даты + статус
  справа, две текстовые строки 14/20, разделитель, кнопка на всю ширину;
- **6043:38527** «Card view» (новая ДС, «Склад_Заказ-товаров») — чекбокс + номер-заголовок
  (акцент) + статус + кебаб, подпись, строки 12/16 колонками (метка 100 + значение), блок дат
  (иконка 18 + подпись/значение), подвал с акцентной кнопкой (в инстансе скрыт).

## Универсальная карточка (агрегат) — что из чего

Сверху вниз, все части — опциональные:

| Блок | Из какого примера |
|---|---|
| чекбокс + номер-заголовок (акцент) + статус справа + кебаб ⋮ | пример 4 |
| подпись под заголовком (серая; тёмная — модификатор `--primary`) | серая — примеры 1, 4; тёмная — 2–3 |
| иконочные строки (иконка + текст; иконка-действие в конце строки) | примеры 1, 2 (мини) |
| строки данных 14/20 «метка → значение» | примеры 1–2 |
| блок дат (2 колонки: иконка 18 + подпись/значение 12/16) | пример 4 |
| действия: контурная кнопка + акцентная | примеры 3 и 4 |

Остальные решения примеров — режимы тех же блоков: статус ставится и строкой под заголовком
(пример 2), и справа от подписи (пример 3); строки данных — 14/20 (по умолчанию) или 12/16
колонками, модификатор `.tc__rows--cols` (пример 4); кнопка — на всю ширину (пример 3)
или справа (пример 4). Всё это показано в примерах-источниках ниже на стенде.

Собрано на компонентах новой ДС:

- **корпус** — «Card view» (`ds-card--custom`: паддинг 12/16 — текущая выгрузка
  компонента, fixes №104; радиус 8; типы `--filled` / `--outlined` / `--shadow` —
  в примерах 1–3 тень, 4 — Filled);
- **статус** — «Status» (`ds-status`, тип Text, без фона): warning #EA7806,
  positive #14B456, accent #448AFF, neutral #616161;
- **чекбокс** — «Checkbox» (`ds-checkbox`; иконка 20 — SVG, подключается
  `checkbox-icons.css`, Material-шрифт не нужен);
- **кебаб** — `ds-icon-size--6x` + `ds-icon-size--state` (иконка 24 `more-vert` / `more-horiz`);
- **кнопки** — «Button» (`ds-btn`, Size=M: 36, r8);
- **разделитель** — «Divider» (`ds-divider`, 1px #E0E0E0);
- **чип в значении** — «Element cell» со статусом (`ds-element-cell--status`, пример 4: «ПРК»);
- **строки данных, иконочные строки, блок дат, подписи** — своя разметка организма
  на токенах (в коде ДС отдельных классов для этих строк карточки нет).

## Размеры (из примеров)

- корпус: паддинг 12/16 (в примерах 16 со всех сторон), радиус 8; ширина — по
  контейнеру (в примерах 328; пример 4 — 375);
- между блоками — 12 (примеры 3–4); в примерах 1–2 — 8 (страница может задать `--tc-gap: 8px`);
- заголовок — 16/24 medium; подпись — 12/16 (серая #616161; тёмная — модификатор `--primary`);
- строки данных: 14/20 #333, паддинг 2 → шаг 24, гэп 4 (примеры 1–2); колоночные —
  12/16, метка 100 (#616161) + значение (#333), гэп 16, шаг строк 8 (пример 4);
- иконочные строки: пара «иконка + текст», внутри пары гэп 8 (в мини — 4), между
  парами 16, высота строки 24;
- блок дат: две равные колонки (иконка 18 + подпись 12/16 #616161 / значение 12/16 #333), гэп 8;
- действия: кнопки ДС 36, гэп 8 — на всю ширину (пример 3) или справа (пример 4);
- разделители — по ширине контента (296 = 328 − 32).

**Расхождения (как есть, не выравнивались):** цвета старой ДС переведены на токены
новой: заголовок и строки #212121 → #333, подписи #616161; статусы старых примеров
(#FFAB40 / #00C853) — компонент Status новой ДС (#EA7806 warning / #14B456 positive);
иконки: в примерах 1 и 3 — 20, в примере 2 (мини) и в блоке дат примера 4 — 18
(в организме размер задаёт разметка, как в источнике); тень примеров 1–3 — старая
(3 слоя #9E9E9E) — в организме тип корпуса новой ДС `ds-card--shadow` (Shadows/01 dp Sl);
кнопка «продлить» в примере 3 капсом (старая ДС) — в организме регистр как на остальных
стендах ДС; чекбокс: в Figma инстанс 24 (глиф 18), в коде ДС — 20×20; в примере 4 подвал
с кнопкой «Подробнее» скрыт — в универсальной карточке показан акцентной кнопкой; паддинг
корпуса — по текущей выгрузке Card view (12/16, fixes №104), поэтому высоты
конфигураций отличаются от примеров на несколько пикселей.

## Адаптив и работа пальцем (тач)

Организм — адаптив: им работают с телефона и планшета — **пальцами, тач-нажатиями**
(требование владельца, 15.10.2026: «это адаптив и работать будут пальцами, тач нажатия»).
Поэтому в адаптивных видах ховер-механики не проектируются — состояния даются нажатием
(в карточном виде Table ховеры убраны тем же решением; в css ДС ховеры пока не обёрнуты
в `@media (hover: hover)` — sticky-hover на тач, журнал №26).

Далее (направление владельца): «возможно далее нужно будут применить паттерны и механики
для адаптива и мобилы» — применяются к организму по мере появления; механика записывается
сюда и в журнал (№186).

## Переключатели и модификаторы (как части компонента)

| Часть | Атрибут на корне |
|---|---|
| Чекбокс | `data-tc-check="off"` |
| Кебаб | `data-tc-kebab="off"` |
| Статус | `data-tc-status="off"` |
| Иконочные строки (+ разделитель) | `data-tc-icons="off"` |
| Блок дат (+ разделитель) | `data-tc-dates="off"` |
| Действия (+ разделитель) | `data-tc-actions="off"` |

Нет атрибута — часть показана (дефолт). То же из js:
`TableCard.set(блок, { icons:false, dates:false })`.

Модификаторы вида: `.tc__rows--cols` — строки 12/16 колонками; `.tc__caption--primary` —
тёмная подпись; `.tc__title--accent` — заголовок-ссылка (акцент); `.tc__pair--mini` —
гэп 4 в паре; `.tc__pair-text--secondary` — серый текст 12/16 иконочной строки;
`.tc__actions--end` — действия справа; `.tc__actions--full` — кнопки на всю ширину;
`--tc-gap` на корне — гэп между блоками (по умолчанию 12).

## Подключение

```html
<link rel="stylesheet" href="../Design-System/organisms/app-table-card-adaptive/table-card-adaptive.css?v=2">
<script src="../Design-System/organisms/app-table-card-adaptive/table-card-adaptive.js?v=2" defer></script>
```

Для карточки с чекбоксом страница дополнительно подключает чекбокс ДС (в
`components/index.css` его нет):

```html
<link rel="stylesheet" href="../Design-System/components-web/components/Checkbox_DS/checkbox.css">
<link rel="stylesheet" href="../Design-System/components-web/components/Checkbox_DS/checkbox-icons.css">
```

Ассеты считаются от расположения скрипта — разметка работает с любой страницы
и при переносе папки (тот же приём, что у app-header, header-content, page-footer
и table-header-actions). Страницы-прототипы подключают организм вручную по этим
путям (через `../Design-System/connect.js` он не приходит — блок нужен не каждой странице).

## Разметка (декларативно)

```html
<div class="ds-card ds-card--custom ds-card--shadow tc">
  <!-- шапка: [чекбокс] + заголовок + [статус + кебаб] + подпись -->
  <div class="tc__head">
    <label class="ds-checkbox tc__check"><input class="ds-checkbox__input" type="checkbox"><span class="ds-checkbox__box"></span></label>
    <div class="tc__head-main">
      <div class="tc__title-row">
        <span class="tc__title">Заголовок</span>
        <span class="tc__head-right">
          <span class="ds-status ds-status--warning ds-status--text tc__status"><span class="ds-status__label">Черновик</span></span>
          <span class="ds-icon-size ds-icon-size--6x ds-icon-size--state tc__kebab" role="button" tabindex="0" aria-label="Действия"><img data-tc-icon="more-vert" width="24" height="24" alt=""></span>
        </span>
      </div>
      <span class="tc__caption">от 30.09.2026</span>
    </div>
  </div>
  <div class="ds-divider ds-divider--m tc__divider tc__divider--icons"></div>
  <!-- иконочные строки: иконка + текст (иконка-действие — в конце строки) -->
  <div class="tc__irows">
    <div class="tc__irow"><span class="tc__pair"><img data-tc-icon="package" width="20" height="20" alt=""><span class="tc__pair-text">Томаты сладкие 500 г</span></span></div>
  </div>
  <div class="ds-divider ds-divider--m tc__divider"></div>
  <!-- строки данных: 14/20 (вид A) или 12/16 колонками (вид B, .tc__rows--cols) -->
  <div class="tc__rows">
    <div class="tc__row"><span class="tc__row-label">Метка</span><span class="tc__row-value">Значение</span></div>
  </div>
  <div class="ds-divider ds-divider--m tc__divider tc__divider--dates"></div>
  <!-- блок дат -->
  <div class="tc__dates">
    <div class="tc__date"><span class="tc__date-icon"><img data-tc-icon="date-range" width="18" height="18" alt=""></span><span class="tc__date-text"><span class="tc__date-label">Отправка</span><span class="tc__date-value">02.10.2026</span></span></div>
  </div>
  <div class="ds-divider ds-divider--m tc__divider tc__divider--actions"></div>
  <!-- действия -->
  <div class="tc__actions tc__actions--end">
    <button type="button" class="ds-btn ds-btn--m ds-btn--neutral ds-btn--outlined"><span class="ds-btn__label">Продлить</span></button>
    <button type="button" class="ds-btn ds-btn--m ds-btn--accent ds-btn--filled"><span class="ds-btn__label">Подробнее</span></button>
  </div>
</div>
```

- Статус можно ставить тремя способами (все — в примерах-источниках): в строке заголовка
  справа (`.tc__head-right`, пример 4), своей строкой под заголовком (`.tc__status-row`,
  пример 2), в строке подписи справа (`.tc__caption-row`, пример 3).
- Иконочные строки: `.tc__irows` → `.tc__irow` → `.tc__pair` (иконка + текст;
  `--mini` — гэп 4), несколько пар в строке — через гэп 16, иконка-действие в конце —
  `.tc__irow-end`.
- Текстовые строки (пример 3): `.tc__texts` → `.tc__text`.
- Ненужные части можно просто не размечать (или выключать атрибутами `data-tc-*`).

## Правила

- Клики не заданы: чекбокс, кебаб и кнопки — действия страницы, обработчики вешает она.
  Скрипт организма делает только две вещи: подставляет иконки (`img[data-tc-icon]` → SVG
  из этой папки) и переключает части (`TableCard.set`).
- Иконки — точные SVG из Figma (файл иконок ДС): `more-vert`, `more-horiz`, `package`
  (коробка, пример 1), `warehouse` (склад), `local-shipping`, `shopping-cart`,
  `credit-card`, `chat-bubble`, `date-range`; 24-сетка, цвет зашит #616161 (Icon/Primary);
  глифы не заменять Material-шрифтом.
- Демо стенд — `demo.html`: первый блок — универсальная карточка (агрегат) с тумблерами
  частей; ниже — примеры-источники (те же блоки в контексте макетов).
- Правки — только здесь.
