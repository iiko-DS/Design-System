Кадр контента (заглушка)

Это демо стенд хедера контента: сверху — сам блок (шапка раздела), ниже — заглушка контентной зоны. Страница подключает ДС и header-content — тот же набор, что и страницы-прототипы.

  • пресеты сверху меняют ширину кадра — блок растягивается по ширине контентной зоны;
  • тумблеры повторяют булевы свойства компонента «Header content» (Стрелка назад, Подпись, Статус, Показ дополнения, Поиск, Кнопки действий); дефолт — всё включено;
  • клики в организме не заданы: стрелка назад, поиск и кнопки — действия страницы (на стенде клик по поиску раскрывает поле — демонстрационная механика). js организма делает только две вещи: подставляет иконки и переключает части — HeaderContent.set(блок, { arrow: false, … }) или атрибуты data-hc-*="off" на корне;
  • поиск — круглая кнопка Search XS: фон Accent/50, без рамки (обводка пробела ДС — в header-content.css); на стенде клик по ней раскрывает поле Search S — ввод работает, «✕» очищает, Esc или клик мимо — свернуть.
