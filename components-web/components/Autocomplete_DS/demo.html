Пометки для ревью: (а) витрина — 10 вариантов на подложке компонента (#F8F9FC), два ряда, как в Figma (в верхнем ряду фокусных ячеек нет — на месте колонок Focus и Focus+Value пропуски): Empty — подпись-плейсхолдер «Label» 16/24 #616161, Populated — подпись-над-полем 12/16 + значение «Select item» 16/24 #333; (б) фокус — рамка и подпись accent (#448aff), в Focus значение пустое (каретка «|»), в Focus+Value — со значением; (в) ошибка — рамка и подпись красные, у Empty-подписи цвет остаётся #616161; (г) Disable — фон #f5f5f5, рамка #ebebeb, текст #9e9e9e; (д) ховер заморожен классом st-hover — живой ховер живёт в кадре поля (fixes №136); (е) поле — два уровня: обёртка ds-autocomplete-form (свои настройки Variant/State) + внутри инстанс инпута ds-input (настройки: Size/Variant/State; всё поле — из css инпута), состояния — реальными классами инпута и st-hover/st-focus, пробелы инпута — fixes п. 15/16 (журнал №31, 34–37, 91); (ж) слоты Element left/right и Support у всех 10 вариантов в Figma выключены — на стенде не выводим (выведутся разметкой инпута по запросу). Журнал №128, №136, №138, №153, №154, №156.

Пометки для ревью: (а) живой пример компонента «Autocomplete form»: список — компоненты ДС («Select (Сontainer)» + «Select item»); старт — Empty (подпись-плейсхолдер «Город» 16/24, список скрыт), при вводе подпись поднимается (12/16, accent), подсказки фильтруются; выбранная строка при повторном открытии помечается Back selected (#f5f9ff); (б) поле — инстанс инпута (ds-input внутри обёртки автокомплита, как у Селекта); пробелы инпута обойдены fixes п. 15/16, живой ховер — №136; (в) автокомплит — динамический элемент: статичные кадры примеров на стенде не воспроизводим — правило заказчика (только живой пример); (г) поведение (как в Material): открытие — фокус/клик/ввод; при открытии лейбл «Город» уезжает наверх (12/16, accent при фокусе — floating label), а в пустом поле остаётся плейсхолдер-подсказка «Начните вводить название»; стрелки ↑↓ — активная строка (фон hover #F5F5F5, скроллится в видимую зону), Home/End, Enter — подставить, Esc/Tab — закрыть, клик вне — закрыть (пустое поле при закрытии возвращает лейбл вниз); иконки слотов (Element left / Element right) в Figma скрыты — в живом примере не показываются; крестик очистки — слот Element right инпута (ds-input__icon → ds-icon-size--5x ds-icon-size--state, глиф close 14 в 20): виден, когда есть значение, клик/Enter — очистить и открыть полный список; ARIA: input role=combobox + aria-expanded/aria-controls/aria-activedescendant, список role=listbox, пункты role=option + aria-selected; (д) список — 12 значений в зоне 272px со скроллом: системный скроллбар скрыт, полоса компонента Scroll пропорциональна содержимому и перетаскивается; когда прокручивать нечего (мало пунктов/фильтр) — полоса скрыта целиком, а не только ползунок; (е) min-height 406 у контейнера в css — артефакт выгрузки, в списке снят (журнал №128).
