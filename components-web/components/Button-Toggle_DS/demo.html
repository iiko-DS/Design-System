Переключение режима отображения

Компонент позволяет пользователю быстро переключаться между различными режимами отображения данных — список, сетка или карта. Один из вариантов всегда выбран.

Default

Hover

Нажатие (переключение)

Пользователь наводит курсор на нужный вариант, кликает — выбор переключается на новый режим. Предыдущий выбранный вариант деактивируется.

Выбор периода в аналитике

Используется в дашбордах и аналитических панелях для переключения временного диапазона отображаемых данных. Позволяет быстро менять масштаб просмотра.

Default

Hover

Нажатие (переключение)

При переключении периода данные на дашборде обновляются в реальном времени. Текущий период всегда выделен акцентным цветом.

Фильтрация по статусу

Быстрая фильтрация списка элементов по их текущему статусу. Используется в задачниках, списках заказов, заявок или обращений.

Все элементы

Только активные

Только завершённые

Каждый фильтр показывает подмножество данных. «Все» отображает полный список без фильтрации. Пользователь может переключаться в любом порядке.

Множественный выбор параметров

Позволяет пользователю выбирать несколько вариантов одновременно. Используется для настройки фильтров, выбора категорий или тегов. Отличается от одиночного выбора тем, что может быть активно более одного варианта.

Один выбран

Два выбраны

Все выбраны

В отличие от одиночного выбора, пользователь может активировать несколько вариантов. Повторный клик на выбранный вариант снимает выделение.

Заблокированные опции (disable)

Используется когда некоторые варианты временно недоступны для выбора в текущем контексте интерфейса. Компонент не реагирует на наведение и клики по заблокированным вариантам.

Один вариант заблокирован

Hover на заблокированном

Полностью заблокирован

Заблокированные варианты отображаются в приглушённом сером цвете. Курсор не меняется при наведении. Используется для обозначения временных ограничений.

Цветовая семантика

Использование цветовых стилей кнопок для передачи смысловой нагрузки — положительный, отрицательный или предупреждающий результат. Цвет помогает пользователю быстро считывать значение выбора.

Цвет выбранной кнопки передаёт смысл:

  • • Positive (зелёный) — подтверждение, низкая опасность
  • • Warning (жёлтый) — предупреждение, внимание
  • • Negative (красный) — отклонение, высокая опасность
