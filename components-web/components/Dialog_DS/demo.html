Пометки для ревью: (а) Basic — живой диалог в составе набора Dialog view (State=Default: шапка + контент + подвал), поверх затемнения — компонент Backdrop (ds-backdrop); прозрачность слоя 15% (как в Figma) в css не выгружается — задана обвязкой (журнал №194); (б) закрывают — крестик (слот ds-dialog-header__icon → инстанс Icon size ds-icon-size--6x; у живого крестика — `--state`: при наведении подложка 32×32 #EBEBEB, при нажатии #E0E0E0, как State=Hover в Figma), Esc, кнопка «Подробнее» или клик по затемнению; «Открыть диалог» возвращает окно (кнопка — обвязка стенда); (в) паддинги/гэпы шапки и контента — обвязка на токенах; скругление корня (12) обрезает содержимое и выравнивание кнопки вправо — в компоненте (fixes.css п. 43); фон описания шапки — артефакт css, снят в fixes.css (п. 31); (г) примеры канвы (16 инстансов: «Удалить карту?», «Ошибка сохранения цен», «Импорт» и др.) на стенде не воспроизводятся — Basic показывает компонент живьём; (д) в Basic всё работает: диалог открывается/закрывается (крестик, Esc, «Подробнее», клик по затемнению), контент прокручивается колесом, ползунок Scroll перетаскивается и синхронизирован. Журнал №129, №202.
