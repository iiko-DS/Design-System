Как собрать: полоса — отдельный класс (ds-table-header-row / ds-table-content-row), внутри — ячейки (ds-table-header-cell / ds-table-content-cell); ширина колонок задаётся на ячейках (обвязка страницы), порядок колонок в шапке = порядок в строках. Текст ячейки — цепочкой классов Element cell → Text UI (как в Figma; __label — наследие прежних сборок); для контролов внутри — слот __element (вкладки Element cell и ячейки с полями; ячейки внутри строки — как в примере на вкладке Element cell); ячейки-поля (Element Form Field) ставятся вместо ячейки контента — сам компонент и есть ячейка. Зебра/выделение — классы --zebra / --selected на полосе. Полный порядок сборки — блок «Как собрать таблицу целиком» в спецификации. Обходы выгрузки — fixes.css п. 22 (журнал №109; №1 — швы шапки, №4 — развёртка полос).
