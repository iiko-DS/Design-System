Free Input

Пользователь может вводить произвольные значения. Выпадающего списка вариантов нет. Значение преобразуется в Chip после клика на Enter или запятой. После создания Chip фокус остается в поле ввода, чтобы пользователь мог продолжить добавлять значения.

Autocomplete

Пользователь выбирает значения из списка. При активации поля открывается выпадающее меню с доступными вариантами. Пользователь может искать значения с помощью ввода текста. Выбранные значения преобразуются в Chip и исключаются из списка доступных вариантов.

Можно создать новую категорию

Если введенное значение отсутствует в списке, пользователю предлагается создать новый вариант. Новые значения могут быть созданы через действие «Добавить». Создание также может быть подтверждено клавишей Enter или запятой. После создания новой категории фокус остается в поле ввода, чтобы пользователь мог продолжить добавлять значения.

Редактирование chips внутри chips input

Один клик по chip переводит его в режим редактирования. Chip остается на своем месте, внутри появляется текстовый курсор. При необходимости открывается выпадающий список. Enter и потеря фокуса — сохранить изменения. Если текст очищен полностью — chip удаляется.

Перетаскивание

Пользователь может изменить порядок Chips с помощью перетаскивания. Во время перетаскивания между Chips отображается индикатор позиции вставки, показывающий место, куда будет перемещен элемент. После отпускания указателя Chip занимает новую позицию, а компонент Chips input возвращается в дефолтное состояние.

Отображение курсора

При получении фокуса текстовый курсор отображается после последнего Chip. Поле ввода располагается в конце списка Chip и переносится на новую строку, если на текущей строке недостаточно места. Минимальная ширина поля ввода 150px.
