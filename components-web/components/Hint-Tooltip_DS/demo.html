Пометки для ревью: (а) 10 вариантов как в Figma: Size Complex / Single × Orientation Default/Up/Down/Right/Left; Complex = header + content + footer (250×120, со стрелкой 124), Single = одна строка (250×36, со стрелкой 40); (б) стрелка — форма 8×4 из Figma (#424242), в Default её нет; (в) Complex content — без иконок слева/справа (как в Figma), иконки — в header и в Single; (г) иконки — инстансы «Icon size» Size=20 → на стенде обёрнуты в ds-icon-size--5x; (д) футер: текст «1 из 4» (14/20 medium) + Button group ДС (Button icon S Accent Filled + Button S Accent Filled «Далее»); (е) в css цвет стилей Hint header одинаковый белый (пер-стилевые цвета не разнесены) — решить в ДС; (ж) в css стрелка — полоса без формы; форма задана обвязкой стенда (8×4 из Figma); фон #424242 и скругление r8 живут на теле (`snap-hint-inner`), а не на корне — иначе носок-стрелка того же цвета сливается с фоном. Журнал №132, №258.
