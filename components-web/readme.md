# components-web

Папка внутри репозитория `DS` — чистые HTML/CSS компоненты из токенов ДС (прослойка).

## Ручные файлы (генератор их не трогает)

Генератор Фигма→CSS пишет в `components/<Имя>_DS/` только css и перезаписывает их при обновлении.
Всё ручное лежит рядом и обновлениями не затрагивается:

- `fixes.css` (корень) — правки артефактов генерации, подключается последним;
- `<имя>.js` — поведение компонента, если у компонента оно есть (эталон: `components/Datepicker_DS/datepicker.js`);
- `demo.html` — демо-стенд компонента (эталон: `components/Datepicker_DS/demo.html`);
- журнал находок по ДС — `Design-System/fixes.md` (в корне репозитория).
