Button — режим Desktop / Mobile

Один и тот же класс .ds-btn, разметка не меняется. Размеры приходят из токенов, режим переключается атрибутом data-mode (файл components-mobile/modes.css). Здесь оба режима стоят рядом: в Figma режим глобальный на файл, два варианта одновременно не показать.
