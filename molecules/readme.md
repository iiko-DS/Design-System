# molecules — молекулы дизайн-системы

Мелкие сборки из компонентов ДС, которые повторяются на страницах (подсказка, чипы-фильтры,
строка поиска с кнопками, мини-формы и т.п.). Папка пока пустая: первая молекула появится,
когда будет её состав.

Формат — как у организмов (`../organisms/`, эталон — `../organisms/app-sidenav/`):
**папка = один блок**, внутри:

- `<имя>.css` — вид: только классы и токены ДС; локальные правки помечаются «пробел ДС»;
- `<имя>.js` — поведение и вставка разметки (если нужно); ассеты считаются от расположения
  своего скрипта, чтобы блок работал с любой страницы;
- `readme.md` — назначение, подключение (2 строки), что где править;
- `demo.html` — **демо стенд** (страница проверки со всеми состояниями).

Подключение: у подключателя `../Design-System/connect.js` — флагом `data-molecules="имя"` (добавит css и js сам);
вручную — `../Design-System/molecules/<имя>/<имя>.css` (+ `.js` при наличии).

Что добавлено «от себя» (чинить в Фигме) — живёт в общем журнале `Design-System/fixes.md` (раздел
компонента, со статусами): в коде — метка «пробел ДС №N», в readme блока — строка-указатель
на раздел. Тексты в двух местах не дублируются.
